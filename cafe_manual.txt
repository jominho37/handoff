[주문 받는 법]
1. 손님이 카운터에 오시면 밝은 표정으로 "안녕하세요, 주문 도와드릴게요!"라고 인사한다.
2. 주문을 받을 때 음료 사이즈(레귤러/라지), 온도(핫/아이스), 당도 조절, 휘핑 추가 여부를 꼭 확인한다.
3. 주문 내용을 포스기(POS)에 입력한 뒤 "주문하신 내용 확인해드릴게요"라고 말하며 주문 내역을 읽어준다.
4. 테이크아웃인지 매장 이용인지 반드시 확인한다. 매장 이용은 머그컵, 테이크아웃은 일회용 컵을 사용한다.
5. 진동벨을 드리며 "음료 나오면 진동벨이 울립니다"라고 안내한다.

[계산 및 결제]
- 카드 결제: 포스기에서 결제 버튼 누른 뒤 카드리더기에 카드를 꽂거나 태그한다.
- 현금 결제: 포스기에서 현금 결제 선택 → 받은 금액 입력 → 거스름돈 확인 후 전달. 현금은 반드시 금고에 바로 넣는다.
- 카카오페이/네이버페이: 포스기 하단 간편결제 버튼 선택 → QR코드 스캔.
- 쿠폰 사용 시: 결제 전에 먼저 쿠폰을 등록해야 한다. 결제 완료 후에는 쿠폰 적용이 불가하다.
- 영수증은 요청 시에만 출력한다. "영수증 필요하세요?"라고 묻지 않아도 된다.

[손님 응대 매뉴얼]
- 기본 인사: 입장 시 "안녕하세요!", 퇴장 시 "감사합니다, 안녕히 가세요!"
- 음료 제공 시: "주문하신 [음료명] 나왔습니다. 맛있게 드세요!"
- 손님이 메뉴를 고르지 못하고 계실 때: "저희 매장 인기 메뉴는 아이스 카페라떼와 돌체라떼입니다"라고 자연스럽게 추천.
- 컴플레인 발생 시: 절대 반박하지 않는다. "불편을 드려 죄송합니다"라고 먼저 사과한 뒤 점장에게 즉시 보고한다.
- 음료 맛 이상 클레임: "바로 새로 만들어 드리겠습니다"라고 말하고 음료를 다시 제조한다.
- 아이 동반 손님: 뜨거운 음료는 반드시 뚜껑을 닫아서 제공하고, 빨대를 함께 드린다.

[테이블 정리]
- 손님이 나가신 후 3분 이내에 테이블을 정리한다.
- 정리 순서: 컵/접시 수거 → 테이블 물티슈로 닦기 → 의자 정렬 → 바닥에 흘린 것 있으면 청소.
- 수거한 머그컵은 바로 싱크대에 넣고, 1시간에 한 번은 모아서 세척한다.
- 테이크아웃 컵은 분리수거: 플라스틱 컵은 투명 분리수거함, 종이컵은 종이류 수거함에 버린다.

[매장 음악 관리]
- 매장 음악은 카운터 뒤 태블릿에서 "카페 핸드오프 플레이리스트" 앱으로 재생한다.
- 오전(08:00~12:00): "Morning Jazz" 플레이리스트 선택.
- 오후(12:00~17:00): "Afternoon Bossa Nova" 플레이리스트 선택.
- 저녁(17:00~마감): "Evening Acoustic" 플레이리스트 선택.
- 볼륨은 태블릿 기준 40~50% 유지. 손님이 "음악 좀 줄여주세요"라고 하면 30%로 낮춘다.
- 음악이 안 나올 때: 태블릿 블루투스 연결 확인 → 스피커 전원 확인 → 앱 재시작 순서로 점검.

[위생 관리]
- 손 씻기: 음료 제조 전, 음식물 취급 후, 쓰레기 처리 후 반드시 비누로 30초 이상 손을 씻는다.
- 앞치마: 근무 시작 시 깨끗한 앞치마를 착용하고, 오염 시 즉시 교체한다.
- 유통기한 관리: 매일 오픈 시 우유, 생크림, 요거트의 유통기한을 확인한다. 당일 기한 만료 제품은 사용하지 않고 폐기한다.
- 블렌더/쉐이커: 사용 후 매번 물로 헹군 뒤 다음 음료 제조에 사용한다. 맛이 섞이지 않도록 주의.
- 얼음 취급: 반드시 전용 스쿱을 사용한다. 절대 맨손으로 얼음을 만지지 않는다.
- 매장 바닥: 2시간에 한 번 물걸레 청소. 물이 엎질러진 경우 즉시 닦아 미끄럼 사고를 방지한다.

[마감 업무 (마감 시간 ~ +1시간)]
1. 마지막 주문 마감 30분 전에 "라스트 오더 안내드립니다"라고 매장 내 안내.
2. 에스프레소 머신 청소: 역세척(백플러시) 1회 실시 + 추출구 분리 후 세척.
3. 그라인더 잔여 원두 제거 및 호퍼 닦기.
4. 블렌더 완전 분해 세척 후 건조.
5. 시럽/소스 뚜껑 닫고 냉장 보관이 필요한 것(생크림, 연유)은 냉장고에 넣기.
6. 싱크대 모든 컵/도구 세척 및 건조대 정리.
7. 테이블 전체 물티슈 닦기 + 의자 올리기.
8. 테라스 어닝 접기 + 외부 테이블/의자 정리.
9. 쓰레기통 비우기: 일반 쓰레기, 재활용 분리하여 매장 뒤편 수거장에 배출.
10. 포스기(POS) 마감 정산: 매출 내역 확인 → 현금 시재 확인 → 카드 매출과 포스기 기록 대조 → 정산 완료 버튼.
11. 모든 전등, 에어컨, 스피커 전원 끄기. 냉장고와 냉동고는 끄지 않는다.
12. 출입문 잠금 확인 후 점장에게 카카오톡으로 "마감 완료" 메시지 전송.

[결근 및 근무 변경]
- 결근: 최소 하루 전까지 점장에게 연락해야 한다. 당일 결근은 반드시 전화로 알린다(카톡 불가).
- 대타 구하기: 단체 카카오톡방 "핸드오프 알바생"에 대타 요청 메시지를 올린다. 대타가 확정되면 점장에게 보고.
- 지각: 10분 이상 늦을 경우 점장에게 미리 전화한다. 무단 지각 3회 시 경고 조치.
- 근무 변경: 다른 알바생과 협의 후 점장 승인을 받아야 확정된다. 일방적인 변경은 불가.

[비상 대처 매뉴얼]
- 포스기(POS) 결제 오류 시: 전원을 껐다 켜지 말고 카드리더기 연결선을 뺏다 다시 꽂으세요.
- 원두가 다 떨어졌을 때: 창고 3번 선반 아래쪽에 박스가 있습니다.
- 손님이 음료를 쏟았을 때: 당황하지 말고 "다치신 곳 없으세요?"라고 먼저 물은 뒤, 대걸레는 주방 안쪽 배수구 옆에 있습니다.
- 화재 발생 시: 즉시 119 신고 → 소화기(카운터 옆, 주방 입구)로 초기 진화 시도 → 진화 불가 시 손님 대피 유도(정문, 비상구).
- 정전 시: 냉장고/냉동고 문을 열지 않는다. 점장에게 즉시 연락 후 지시에 따른다.
- 도난/분실 신고: 손님이 물건을 잃어버렸다고 하면 분실물 보관함(카운터 아래 서랍)을 확인하고, 없으면 연락처를 받아 점장에게 전달한다.
